# 방안 뜨기 도안 제작

코바늘 방안 뜨기(필레 크로셰)용 격자 도안을 만드는 웹 도구.
설치 없이 브라우저만 있으면 됩니다.

## 쓰는 법

**웹에서 열기** — 폰·태블릿·PC 어디서든:

### https://sojung48.github.io/filet-crochet/

폰에서 자주 쓴다면 브라우저 메뉴의 **홈 화면에 추가**를 해두면 앱처럼 열립니다.

**내려받아 쓰기** — 저장소를 통째로 받아 `index.html`을 더블클릭해도 됩니다.
(HTML 파일 하나만 옮기면 동작하지 않습니다. 폴더째 받으세요.)

## 조작

| | |
|---|---|
| 그리기 / 지우기 | 칸을 누르거나 끌기 |
| 사각형 | 시작점에서 끝점까지 끌기 |
| 채우기 | 이어진 빈 영역을 한 번에 채움 |
| 확대·축소 | 두 손가락 핀치, 또는 `+` / `−` 버튼 |
| 실행취소 / 재실행 | 위쪽 ↶ ↷ 버튼 |

PC에서는 단축키도 됩니다: `B` 그리기, `E` 지우기, `R` 사각형, `G` 채우기,
`Ctrl+Z` 실행취소, `+` / `−` 확대축소, `0` 화면 맞춤.

## 도안 읽기

오른쪽 패널에 행별 지시문이 자동으로 만들어집니다.

```
3행 ←: 2 filled, 5 open, 3 filled
```

1행이 맨 아래이고, 홀수 행은 오른쪽→왼쪽(`←`), 짝수 행은 왼쪽→오른쪽(`→`)으로
읽습니다. 지그재그로 뜨지 않는다면 패널에서 이 옵션을 끄면 모든 행을 같은
방향으로 읽습니다.

## 저장

- **자동 저장** — 편집하면 브라우저에 저장됩니다. 단, **기기마다 따로** 저장되므로
  PC에서 그린 도안이 폰에 자동으로 나타나지는 않습니다.
- **기기 간 옮기기 / 백업** — `JSON 내보내기`로 파일을 저장하고, 다른 기기에서
  `JSON 가져오기`로 불러오세요.
- **인쇄 / PNG** — 화면 배율과 상관없이 흑백 고해상도로 출력됩니다.

## 개발

빌드 도구나 런타임이 필요 없는 정적 웹앱입니다.

원본은 `js/*.js` (ES 모듈)이고, `js/bundle.js`는 이를 하나로 합친 생성 파일입니다.
`file://`에서 ES 모듈이 CORS로 차단되기 때문에, 더블클릭만으로 열리도록 번들을
씁니다. **`js/*.js`를 고친 뒤에는 반드시 다시 빌드하세요:**

```
node build.mjs
```

| 파일 | 역할 |
|---|---|
| `js/pattern.js` | 도안 데이터 모델, JSON 직렬화 |
| `js/renderer.js` | 캔버스 렌더링, 좌표 변환 |
| `js/reading.js` | 행별 지시문 생성 |
| `js/history.js` | 실행취소 / 재실행 |
| `js/storage.js` | 로컬 저장, 파일 입출력 |
| `js/image.js` | 이미지 → 2색 도안 변환 |
| `js/text.js` | 텍스트 → 도안 변환 (비트맵 글꼴) |
| `js/main.js` | 입력 처리, 도구, 전체 연결 |

칸 값은 boolean이 아니라 팔레트 인덱스로 저장합니다. 나중에 다색 도안으로
넓힐 때 저장 포맷을 바꾸지 않아도 되게 하기 위함입니다.

모듈들은 하나의 스코프로 합쳐집니다. 두 파일이 같은 이름을 최상위에
선언하면 뒤엣것이 앞엣것을 덮어쓰므로, 빌드가 이를 검사해 막습니다.

## 글꼴

글자 도안에는 **[갈무리Mono9](https://github.com/quiple/galmuri)**를 씁니다.
quiple(이민서) 제작, SIL Open Font License 1.1.

`fonts/GalmuriMono9.woff2`로 함께 배포하며 라이선스 전문은
`fonts/OFL.txt`에 있습니다. 외부 CDN을 쓰지 않는 이유는 이 앱이
`index.html`을 더블클릭하는 것만으로도 동작해야 하기 때문입니다.

글자 모양은 **웹폰트가 아니라 `js/glyphs.js`에서** 옵니다. 폰트에 손으로
찍혀 있는 비트맵을 빌드할 때 미리 꺼내 둔 표입니다(한글 9칸, 영문 5칸,
높이 11칸).

브라우저에 글자를 그려달라고 하면 기기마다 결과가 달랐기 때문입니다 —
PC(DirectWrite)와 폰(CoreText)의 글자 그리는 엔진이 다르고, 외곽선
가장자리를 어디서 자르냐에 따라 칸 하나가 갈립니다. 같은 글자를 넣어도
PC와 폰의 도안이 어긋났습니다. 표를 쓰면 어디서든 똑같이 나옵니다.

폰트를 새 버전으로 바꿀 때만 다시 뽑으면 됩니다:

```
node make-glyphs.mjs GalmuriMono9Bitmap-Regular-2.40.3.ttf
```
